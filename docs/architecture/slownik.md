# Słownik języka FieldService

Wszechobecny język: te same słowa w rozmowie z biznesem, na ekranie, w testach i w kodzie.

| Pojęcie | Znaczenie w FieldService |
|---|---|
| Zlecenie | sprawa klienta: urządzenie, adres, usterka, termin SLA; należy do modelu Zlecenia (serwer) |
| Wizyta | jedna obecność technika u klienta w ramach zlecenia; ma przebieg, zakres prac, podpis i wynik |
| Zakres prac | to, co klient podpisuje: czynności i zużyte części; zmienia się w trakcie wizyty |
| Czynność | wykonana praca (kod czynności i opis) |
| Zużyta część | część zamontowana u klienta podczas wizyty |
| Podpis klienta | akceptacja konkretnego zakresu prac przez klienta |
| Wynik wizyty | jak skończyła się wizyta: naprawione, potrzebna kolejna wizyta (np. brak części) albo nie naprawiono |
| Protokół | dokument z wizyty wyliczany z zakresu prac – klient widzi go przed podpisem |
| Zapas części | stan jednej części w jednym magazynie i jej rezerwacje (model Magazyn, serwer) |
| Rezerwacja | odłożenie sztuk części dla wizyty; wygasa po czasie |
| Auto technika | części, które technik ma przy sobie |
| Dyspozytor | przyjmuje zgłoszenie klienta, zakłada zlecenie, planuje wizyty, może je anulować albo przenieść |
| Brygada | dwóch techników na jednej wizycie, każdy z telefonem |
